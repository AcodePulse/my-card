# Modern Personal Portfolio Card for Instagram

A sleek, highly responsive, and minimalistic developer portfolio card built with modern HTML5 and CSS3. Designed with a dark-mode aesthetic, glowing background accents, and interactive elements tailored for seamless desktop and mobile navigation.

### ✨ Key Features
- **Dark Theme & Modern Aesthetics:** Ambient glow background with custom CSS variables and clean layout.
- **Cross-Platform Responsive:** Fully adapted for mobile, tablet, and desktop screens.
- **Touch-Optimized Interaction:** Enhanced mobile UX with active state handling and automatic focus reset.
- **Direct Mail Integration:** Integrated one-click Gmail Web composer for effortless contact.

### 🛠️ Tech Stack
- **HTML5:** Semantic markup for optimal structure and accessibility.
- **CSS3:** Custom properties, Flexbox, CSS Grid, and responsive media queries.
- **Font Awesome:** Scalable vector icons for clean visual cues.
